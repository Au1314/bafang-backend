## 后端设计

### 主要职责

1. 为两个前端的各项功能进行逻辑操作，并提供响应接口
2. 与高德 api 进行交互，获取地图导航、实时位置等信息
3. 处理用户提交的认证信息、导航请求、呼叫请求等
4. 存储平台的用户数据、私桩数据、认证信息等

### 接口设计

1. Get 请求以 param 的形式传递参数
2. Post 请求以 json 的形式传递参数
3. 所有接口返回数据均以 json 的形式返回
   返回形式
   '''
   {
   "code": 200,
   "msg": "success",
   "data": {
   "key1": "value1",
   "key2": "value2"
   }
   }
   '''
4. 管理端接口路径以 ip:port/api/v1/admin 开头
5. 用户端接口路径以 ip:port/api/v1/user 开头

### 包结构设计

主包结构

```
com.baffang
├── common    // 双端通用公共模块
│   ├── entity    //存放实体类，对应数据库表
│   ├── exception    //处理业务异常与全局异常
│   ├── enums    //存放枚举类
│   ├── constant    //存放常量类
│   └── util    //存放工具类
│   └── result    //存放返回包装类
├── config    // 配置模块
├── framework    // 框架模块
├── admin    // 管理端模块
│   ├── controller
│   ├── service
│   │   └── impl
│   ├── mapper
│   ├── dto
│   └── vo
│   └── ...
└── user    // 用户端模块
    ├── controller
    ├── service
    │   └── impl
    ├── mapper
    ├── dto
    └── vo
    └── ...
```
