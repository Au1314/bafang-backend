# 功能设计（更新版）

## 1. 用户端设计

### 1.1 个人信息管理

1. 登录、注册、重置密码
2. 个人资料编辑（签名等）
3. 绑定/解绑账号
4. 密码修改
5. 隐私控制：
   - 控制他人是否能看到自己绑定的车辆
   - 控制他人是否能看到自己的充电桩

### 1.2 个人充电桩管理

1. 认证/新增/解绑充电桩
2. 认证进度显示
3. 价格设置：支持固定/动态两种模式
4. 开启/关闭时间设置
5. 手动开启/关闭充电桩
6. 查看/管理预约记录

### 1.3 车辆信息管理

1. 认证/新增/解绑车辆
2. 认证进度显示
3. 修改相关参数

### 1.4 导航功能

1. 基础地图导航
2. 搜索目标
3. 公桩导航
4. 私桩导航
5. 智能路线规划
   - 充电桩路线规划（短途）：综合各种因素，推荐最适合的充电桩
   - 长途路线规划：确保路线上始终有多个充电桩可用，解决续航焦虑
6. 充电桩状态联动：实时更新充电桩状态（如 "原本空闲 → 已占用"，自动推荐备选桩）

### 1.5 充电桩使用

1. 预约私桩（仅私桩）
2. 联系桩主（仅私桩）
3. 扫码充电（公桩、私桩通用）
4. 故障上报（公桩、私桩通用）
5. 私桩问题举报（仅私桩）
6. 评论（公桩、私桩通用）
7. 查看充电记录

### 1.6 呼叫功能

1. 呼叫其他车主进行 V2V（电量银行，根据充电量给予激励积分）
2. 呼叫紧急救援
3. 救援进度显示

### 1.7 论坛功能

1. 发布帖子
2. 搜索帖子
3. 回复帖子
4. 点赞帖子
5. 收藏帖子
6. 管理员审核
7. 互动限制：黑名单用户无法评论/点赞，避免恶意骚扰
8. 发帖激励（积分）

### 1.8 黑白名单功能

1. 添加或删除车主/充电桩到黑名单
2. 将某充电桩添加到收藏列表，优先推荐

### 1.9 智能客服功能

1. AI 客服
2. 人工客服

### 1.10 支付功能

1. 平台支付体系：
   - 用户充值
   - 付款功能
   - 扣费设置（手动付款/自动扣费）
   - 优惠券管理
   - 交易申诉
   - 充电完成后自动扣费（初期仅平台模拟充电桩）
2. 线下支付体系：
   - 用于实际充电桩
   - 交易不通过平台，平台仅提供导航服务

### 1.11 消息通知功能

1. 车辆认证结果通知
2. 充电桩认证结果通知
3. 呼叫通知（附近车主收到呼叫消息）
4. 预约提醒（私桩被预约后桩主收到提醒）

### 1.12 积分管理

积分来源于 V2V 救助，论坛发帖以及各种平台活动

1. 兑换商品（待定）
2. 兑换优惠券（可用于充电付款时折扣）
3. 查看积分来源
4. 提升信誉等级

## 2. 管理端设计

### 2.0 登录注册模块

略，但要注意与用户端做区分，两者并非同一套模块，需要分别开发

### 2.1 权限等级设计

- 超级管理员＞管理员＞客服/紧急响应人员/审核员/论坛管理员＞未分配成员

### 2.2 平台管理（仅超级管理员和管理员可用）

1. 设置成员为管理员（仅超级管理员可用）
2. 新增成员账号（也可主动注册）（默认未分配成员）
3. 设置成员为审核员/客服/紧急响应人员
4. 剥夺成员身份
5. 平台参数配置：
   - 默认呼叫范围
   - 积分奖励规则
   - 日志记录字段
   - 其他平台参数
6. 查看平台日志

### 2.3 统计功能（管理员以上可用）

1. 用户总数
2. 用户日活
3. 私桩认证量
4. 车主认证量
5. 私桩分布数据
6. 交易数据

### 2.4 数据导出与备份功能（超级管理员可用）

1. 数据导出：
   - 审核记录导出
   - 订单&用户数据导出
   - 订单明细/交易流水/退款记录
   - 用户列表/黑白名单/成就激励记录
2. 数据备份与恢复：
   - 备份平台数据
   - 回滚平台数据

### 2.5 审核功能（审核员/客服及以上可用）

1. 私桩认证审核
2. 车主认证审核
3. 充电桩投诉审核
4. 充电桩故障审核
5. 充电桩评论审核（仅被举报后审核）
6. 交易申诉审核
7. 查看审核记录

### 2.6 管理功能（管理员以上可用）

1. 私桩信息管理
2. 用户信息管理：查看、禁用、删除等
3. 订单&支付管理：
   - 订单管理：查看所有订单（私桩预约/V2V/公桩）、订单状态/金额/结算方式
   - 支付管理：查看交易流水/退款记录，手动发起退款（特殊场景）
   - 分账管理：查看桩主收益/平台抽成，支持批量结算
4. 运营管理：
   - 系统日志查询
   - 系统健康状态监控
   - 异常告警配置

### 2.7 响应功能（紧急响应人员及以上可用）

1. 响应紧急呼叫
2. 管理紧急呼叫
3. 查看呼叫记录

### 2.8 论坛管理（论坛管理员及以上可用）

1. 帖子与评论管理（增删改查）
2. 置顶/精华管理
3. 用户举报帖子或评论审核

### 2.9 客服入口（客服及以上可用）

1. 配置 AI 客服参数
2. 人工客服对话
3. 查看对话记录
