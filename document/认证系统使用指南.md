# 认证系统使用指南

## 1. 系统概述

本项目采用基于 JWT（JSON Web Token）的认证机制，实现了无状态的用户认证系统，支持用户端和管理员端两套认证体系。

## 2. Token 结构与信息

### 2.1 Token 生成流程

1. **用户登录**：用户通过登录接口提交用户名和密码
2. **身份验证**：系统验证用户名密码的正确性
3. **生成 Claims**：根据用户类型（管理员/普通用户）生成不同的声明信息
4. **签名加密**：使用密钥对 Claims 进行签名生成 JWT Token
5. **返回 Token**：将生成的 Token 返回给客户端

### 2.2 Token 包含的信息

解析完成后，Token 中包含以下核心信息：

| 字段名      | 类型         | 说明                      |
| ----------- | ------------ | ------------------------- |
| userId      | Long/Integer | 用户的唯一标识符          |
| username    | String       | 用户登录名                |
| authType    | String       | 所属系统："admin"或"user" |
| role        | Integer      | 用户角色代码              |
| permissions | List<String> | 用户权限列表（间接包含）  |

## 3. Token 解析与存储

### 3.1 Token 解析

Token 解析主要在`JwtAuthenticationFilter`过滤器中完成：

```java
// 从请求头获取Token
String token = getTokenFromRequest(request);

// 解析Token
Claims claims = jwtUtil.parseToken(JwtConstants.SECRET_KEY, token);

// 获取关键信息
String username = (String) claims.get(JwtConstants.USERNAME_CLAIM);
String authType = (String) claims.get(JwtConstants.AUTH_TYPE_CLAIM);
```

### 3.2 信息存储位置

解析后的 Token 信息存储在 Spring Security 的`SecurityContextHolder`中：

```java
// 创建认证对象
UsernamePasswordAuthenticationToken authentication = new UsernamePasswordAuthenticationToken(
        userDetails, null, userDetails.getAuthorities());

// 设置认证详情
authentication.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));

// 存储到SecurityContext
SecurityContextHolder.getContext().setAuthentication(authentication);
```

## 4. Token 信息使用

### 4.1 从 SecurityContext 获取当前用户

**通用方式**：

```java
// 获取认证对象
Authentication authentication = SecurityContextHolder.getContext().getAuthentication();

// 验证认证状态
if (authentication != null && authentication.isAuthenticated()
    && !"anonymousUser".equals(authentication.getPrincipal())) {

    // 获取UserDetails对象
    UserDetails userDetails = (UserDetails) authentication.getPrincipal();

    // 获取用户名
    String username = userDetails.getUsername();

    // 获取用户权限
    Collection<? extends GrantedAuthority> authorities = userDetails.getAuthorities();
}
```

**在控制器中使用**：

```java
@RestController
@RequestMapping("/api/v1/user")
public class UserController {

    @GetMapping("/profile")
    public Result<UserInfo> getUserProfile() {
        // 获取当前登录用户信息
        Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
        String username = ((UserDetails) authentication.getPrincipal()).getUsername();

        // 从数据库查询完整用户信息
        UserInfo userInfo = userMapper.selectByUsername(username);
        return Result.success(userInfo);
    }
}
```

### 4.2 使用 JwtUtil 直接解析 Token

```java
// 从请求头获取Token
String token = getTokenFromRequest(request);

// 获取特定信息
Long userId = JwtUtil.getUserIdFromToken(JwtConstants.SECRET_KEY, token);
String username = JwtUtil.getUsernameFromToken(JwtConstants.SECRET_KEY, token);
Integer role = JwtUtil.getRoleFromToken(JwtConstants.SECRET_KEY, token);
String authType = JwtUtil.getAuthTypeFromToken(JwtConstants.SECRET_KEY, token);
List<String> permissions = JwtUtil.getPermissionsFromToken(JwtConstants.SECRET_KEY, token);
```

## 5. 权限控制

### 5.1 权限注解

使用`@RequirePermission`注解进行权限控制：

```java
// 只需要登录即可访问
@RequirePermission(needPermission = false)
@GetMapping("/profile")
public Result<UserInfo> getUserProfile() {
    // 方法实现
}

// 需要特定权限才能访问
@RequirePermission(PermissionConst.USER_CAR_OWNER)
@GetMapping("/vehicles")
public Result<List<VehicleInfo>> getVehicles() {
    // 方法实现
}

// 不需要登录即可访问
@RequirePermission(needLogin = false, needPermission = false)
@GetMapping("/public")
public Result<String> getPublicInfo() {
    // 方法实现
}
```

### 5.2 权限验证流程

1. **请求拦截**：`PermissionInterceptor`拦截所有请求
2. **注解检查**：检查方法或类上是否有`@RequirePermission`注解
3. **登录验证**：如果需要登录，检查 SecurityContext 中是否有认证信息
4. **权限验证**：如果需要权限，检查当前用户是否具有指定权限
5. **继续请求**：验证通过后继续处理请求，否则抛出相应异常

## 6. 代码示例

### 6.1 用户登录流程

```java
@PostMapping(AuthConstants.USER_LOGIN_URL)
public Result<TokenDTO> login(@RequestBody LoginDTO loginDTO) {
    // 创建认证令牌
    UsernamePasswordAuthenticationToken authenticationToken = new UsernamePasswordAuthenticationToken(
            loginDTO.getUsername(), loginDTO.getPassword());

    // 执行认证
    Authentication authentication = authenticationManager.authenticate(authenticationToken);

    // 将认证信息存储到SecurityContext中
    SecurityContextHolder.getContext().setAuthentication(authentication);

    // 获取用户信息
    UserDetails userDetails = (UserDetails) authentication.getPrincipal();
    String username = userDetails.getUsername();
    UserInfo userInfo = userMapper.selectByUsername(username);

    // 生成JWT令牌
    Map<String, Object> claims = new HashMap<>();
    claims.put(JwtConstants.USER_ID_CLAIM, userInfo.getId());
    claims.put(JwtConstants.USERNAME_CLAIM, userInfo.getUsername());
    claims.put(JwtConstants.AUTH_TYPE_CLAIM, "user");
    claims.put(JwtConstants.ROLE_CLAIM, role.getCode());
    String token = JwtUtil.generateToken(
            JwtConstants.SECRET_KEY,
            JwtConstants.USER_TOKEN_EXPIRE_TIME,
            claims);

    // 返回登录结果
    TokenDTO tokenDTO = new TokenDTO();
    tokenDTO.setToken(token);
    tokenDTO.setExpiresIn(JwtConstants.USER_TOKEN_EXPIRE_TIME);
    tokenDTO.setTokenType(JwtConstants.TOKEN_PREFIX);

    return Result.success(tokenDTO);
}
```

### 6.2 自定义权限检查

```java
private boolean hasPermission(String permissionCode) {
    // 获取当前认证用户
    Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
    if (authentication == null || !authentication.isAuthenticated()) {
        return false;
    }

    // 获取用户权限
    Object principal = authentication.getPrincipal();
    if (principal instanceof UserDetails) {
        UserDetails userDetails = (UserDetails) principal;
        // 检查是否包含所需权限
        return userDetails.getAuthorities().stream()
                .anyMatch(authority -> authority.getAuthority().equals(permissionCode));
    }

    return false;
}
```

## 7. 常见问题

### 7.1 Token 过期

**现象**：客户端请求时返回 401 错误，提示"JWT 令牌已过期"

**解决方法**：

1. 客户端重新调用登录接口获取新 Token
2. 实现 Token 刷新机制，使用刷新 Token 获取新的访问 Token

### 7.2 Token 无效

**现象**：客户端请求时返回 401 错误，提示"JWT 令牌无效"

**可能原因**：

1. Token 被篡改
2. Token 格式错误
3. 使用了错误的密钥解析

**解决方法**：

1. 确保客户端正确存储和传递 Token
2. 检查 Token 生成和解析使用的密钥是否一致

### 7.3 权限不足

**现象**：客户端请求时返回 403 错误，提示"权限不足"

**解决方法**：

1. 检查当前用户是否具有访问该接口所需的权限
2. 确认`@RequirePermission`注解配置是否正确

## 8. 最佳实践

1. **Token 安全存储**：客户端应使用安全方式存储 Token，避免明文存储
2. **HTTPS 传输**：所有 API 请求应使用 HTTPS 协议，防止 Token 被窃取
3. **合理设置过期时间**：根据业务需求设置合适的 Token 过期时间
4. **定期刷新 Token**：实现 Token 刷新机制，提高安全性
5. **最小权限原则**：为用户分配最小必要权限，减少安全风险
